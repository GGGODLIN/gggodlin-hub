Platform

  • Magpie routing gateway

    API gateway and quota pool

    An LLM proxy and credential pool for Amazon Bedrock, Anthropic Claude, OpenAI and open-weight models. It fails over when a provider's quota runs out, keeps prompt-cache affinity and reports token use in one place.

    Architecture notes blog.gggodlin.com/blog/model-routing

  • Deterministic agent gates

    CI/CD governance

    Pre-commit and CI checks that run before agent-generated code reaches a human reviewer. They match claims to evidence, run contract tests and hold changes that leave their scope.

    Technical spec blog.gggodlin.com/blog/rule-ladder

  • Cross-model spec and PR review

    Automated review

    Specs and pull requests are stress-tested by more than one model. The review looks for architectural drift, security flaws and unverified assumptions before merge.

    System overview blog.gggodlin.com/slides/model-division

  • Fleet telemetry and spend guardrails

    Observability and FinOps

    Per-seat quota tracking and billing anomaly alerts that fire before a charge lands. Tools on trial get an automatic review date.
